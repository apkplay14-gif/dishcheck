# Є Starlink

Невеликий Android-додаток для зняття ідентифікаційних даних комплекту Starlink
на місці, без інтернету й без облікових записів. Аналог того, що показує StarDebug,
але лише те, що реально потрібно в полі.

## Що вміє

### Головне меню — що зчитувати

На головному екрані є картка **«Що зчитувати»** з галочками. Порядок пунктів = порядок
зчитування:

1. **Номер KIT з коробки** — QR / штрихкод
2. **Серійний номер тарілки** — QR / штрихкод
3. **Серійний номер роутера** — QR / штрихкод
4. **Starlink ID** — по мережі з тарілки
5. **Router ID** — по мережі з роутера
6. **MAC-адреса роутера** — по мережі з роутера

Зняти можна будь-який набір: галочки запам'ятовуються між запусками, і кожен запис
зберігає, з якими саме галочками його знімали.

### Порядок зчитування

Кнопка **«Почати зчитування»** проходить обрані пункти по черзі: спочатку відкриває
сканер на кожен увімкнений QR-крок (у заголовку видно «Крок 2 з 4» і що саме сканувати),
потім опитує тарілку й роутер по мережі. У сканері є кнопка **«Пропустити»** — крок
можна оминути, ланцюжок піде далі.

Будь-яке поле можна виправити руками або пересканувати окремою кнопкою «QR» у картці.
MAC вводиться руками, якщо роутер його не віддав.

### Демо-режим

Для тих, у кого немає Starlink поруч: рецензента Google Play, запису відео й
скріншотів для сторінки в магазині, нового користувача. Кнопка **«Спробувати демо»**
є на картці підключення, поки Starlink не на звʼязку.

- Справжня історія відкладається вбік і не змінюється; демо живе лише в памʼяті,
  у файл не пишеться нічого. Вихід — кнопкою на плашці «Демо-режим».
- В історії одразу два приклади комплектів (учора й сьогодні).
- У сканері зʼявляється кнопка **«Демо-код»** — вона «знаходить» код без камери,
  далі звичайна звірка й підтвердження. Справжні коди теж скануються.
- Опитування тарілки й роутера імітується, мережевих запитів немає.
- «Поділитися» відкриває справжнє вікно надсилання; текст починається з позначки
  «[ДЕМО] … дані вигадані». У самих значеннях теж є DEMO, MAC — з діапазону для
  документації (RFC 7042), тож переслане неможливо сплутати зі справжнім.
- Реклами й прохання оцінити застосунок у демо немає.

### Решта

- Статус підключення до Wi-Fi Starlink з кнопкою в налаштування Wi-Fi.
- **Свої примітки** до кожного комплекту — окреме поле, зберігається разом із записом.
- **Історія** усіх зчитувань з примітками.
- **Поділитися** — стандартне вікно Android, тож у списку зʼявляються WhatsApp,
  Signal, Telegram, Viber, SMS, пошта. У текст ідуть лише обрані пункти, у тому ж порядку.

Усі дані зберігаються **тільки локально**: `history.json` і `capture_settings.json`
у приватній папці додатка. Жодних серверів, аналітики чи мережевих запитів кудись,
окрім самої тарілки й роутера.

## Оформлення

Тема лише темна — так само, як офіційний застосунок Starlink, і на сонці темний
екран з високим контрастом читається краще.

| Роль | Колір | Де |
|---|---|---|
| Ink | `#06080D` | тло застосунку |
| Panel | `#0E1119` | картки |
| Hairline | `#222937` | рамки, роздільники |
| Accent | `#4C8DFF` | кнопки, активні пункти, рамка сканера |
| Online | `#3DDC97` | Starlink відповідає |
| Waiting | `#FFB443` | Wi-Fi є, пристрій мовчить |
| Alert | `#FF6B6B` | помилка, видалення |

Знак — українська «Є» з дуги й перекладини однакової товщини плюс нахилений
еліпс-орбіта. Той самий еліпс ледь помітно підсвічує шапку головного екрана
(`OrbitBackdrop`). Знак намальовано з нуля: це не логотип SpaceX і не запозичена
державна символіка.

Іконка застосунку — адаптивна (`mipmap-anydpi-v26/ic_launcher.xml`): градієнтний
фон, білий знак у безпечній зоні, окремий монохромний шар для тематичних іконок
Android 13+. Плюс 14 іконок інтерфейсу на сітці 24×24 з обведенням 1.8.
Уся графіка векторна — жодного PNG, працює на будь-якій щільності екрана.

Ідентифікатори (серійники, ID, MAC) завжди моноширинні на темній підкладці:
їх читають вголос по символах, і «0» не має бути схожим на «O».

## Мови

Інтерфейс перекладено на **англійську** (типова), **українську**, **польську**,
**іспанську** та **німецьку**. Рядки лежать у `res/values*/strings.xml`.
Пакуються лише ці п'ять локалей — чужі переклади з бібліотек відфільтровані
(`localeFilters` у [app/build.gradle.kts](app/build.gradle.kts)).

На Android 13+ мову застосунку можна обрати окремо від системної:
«Налаштування → Застосунки → Є Starlink → Мова».

Додати ще одну мову — це один новий файл `res/values-XX/strings.xml`
плюс рядок у [locales_config.xml](app/src/main/res/xml/locales_config.xml).

## Реклама

У застосунку є банер унизу головного екрана й збір згоди GDPR. Зараз стоять
**тестові** ідентифікатори Google — нічого не заробляється.

Що лишилось налаштувати, покрокова інструкція: [ADS-SETUP.md](ADS-SETUP.md).
Вимкнути рекламу повністю — `SHOW_ADS = false` в [app/build.gradle.kts](app/build.gradle.kts).

Текст політики конфіденційності лежить у [docs/index.html](docs/index.html).

## Збірка

Потрібен лише **Android Studio** — він приносить із собою JDK та Android SDK.
Зібрано й перевірено на Android Studio 2026.1.3 (JBR 25, SDK Platform 37).

1. `File → Open…` → виберіть папку `d:\CLODE\Starlink`.
2. Дочекайтесь Gradle Sync (перший раз качає Gradle 9.7.1 і залежності).
3. `Build → Build Bundle(s) / APK(s) → Build APK(s)`
   або з терміналу: `gradlew.bat assembleDebug`

Готовий файл: `appuild\outputspk\debugpp-debug.apk`.

Шлях до SDK лежить у `local.properties` (файл не в git). Якщо SDK в іншому місці —
поправте `sdk.dir` або задайте змінну `ANDROID_HOME`.

Для запуску прямо з Android Studio: увімкніть на телефоні «Налагодження по USB»,
підключіть кабелем і натисніть ▶.

Мінімальна версія Android — 8.0 (API 26).

## Як це працює всередині

Starlink віддає дані по gRPC без шифрування (h2c). Замість того щоб «зашивати»
номери полів proto-схеми — вони не задокументовані й змінювались між прошивками —
додаток спершу запитує схему в самого пристрою через **gRPC Server Reflection**
і будує запит по *імені* поля (`get_device_info` / `get_status`). Тому він не
ламається після оновлення прошивки.

Відповідь теж розбирається за іменами: у дереві шукається вкладене повідомлення,
схоже на `DeviceInfo` (має поля `id` та `hardware_version`/`software_version`).
MAC шукається окремо — спершу поле, у назві якого є `mac`, інакше будь-який рядок
формату `XX:XX:XX:XX:XX:XX`; якщо прошивка його не віддає, поле лишається для
ручного вводу.

Реалізація мережі — `okhttp` з `H2_PRIOR_KNOWLEDGE` плюс ручне кадрування gRPC
(1 байт прапорця + 4 байти довжини + payload), без важкої `grpc-java`.

Сокети примусово прив'язуються до Wi-Fi-мережі
(`Network.socketFactory`) — інакше Android може відправити запит на `192.168.100.1`
через мобільний інтернет.

### Резервний режим

Якщо прошивка не віддає рефлексію, у розділі **«Додатково»** можна увімкнути
резервний режим: запит надсилається без схеми, а відповідь розбирається по
wire-формату з упізнаванням значень за виглядом.

Він вимкнений за замовчуванням і пробує лише два номери полів (1008 `get_device_info`
і 1004 `get_status`). Перебирати номери наосліп не можна: у тій самій `oneof`
лежать і команди дії (`reboot`, `stow`), і випадкове влучання перезавантажило б
тарілку.

## Структура

```
app/src/main/java/ua/starlink/reader/
  MainActivity.kt        точка входу, ланцюжок кроків, сканер, share
  MainViewModel.kt       стан екрана, зчитування, історія
  data/                  моделі, галочки меню, локальне сховище (JSON)
  net/
    GrpcChannel.kt       gRPC поверх OkHttp (h2c)
    ReflectionClient.kt  завантаження proto-схеми з пристрою
    StarlinkClient.kt    власне зчитування Dish / Router
    WireWalk.kt          розбір protobuf без схеми (резервний режим)
    NetUtil.kt           Wi-Fi мережа, перевірка доступності
  qr/QrScanActivity.kt   камера + ML Kit, офлайн
  ui/
    Theme.kt             палітра, типографіка, форми
    Components.kt        знак, картки, чіпи, іконки
    Screens.kt           екрани
  util/Sharing.kt        формат тексту й share
res/drawable/            іконка застосунку + 14 іконок інтерфейсу (вектор)
```

## Статус

Код написаний повністю, але **зібрати й перевірити його на пристрої ще не вдалося** —
на цій машині немає Android SDK/JDK. Першу збірку та перевірку на реальному
Starlink треба зробити після встановлення Android Studio. Якщо зчитування не
спрацює — увімкніть «Додатково → Журнал останнього зчитування», там видно, на
якому кроці зупинилось.
