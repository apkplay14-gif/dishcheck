=== КОРОТКИЙ ОПИС (до 80 символів) ===

=== ПОВНИЙ ОПИС (до 4000 символів) ===
Є Starlink — застосунок для швидкого обліку терміналів Starlink (Старлінк) просто на місці встановлення. Наведіть камеру на коробку чи наліпку — і KIT-номер та серійні номери тарілки й роутера вже записані. Starlink ID, Router ID і MAC-адресу застосунок зчитає сам через Wi-Fi вашого Starlink. Без реєстрації, без акаунтів, українською мовою.

Не треба розбиратися, де знайти KIT-номер чи Starlink ID, і переписувати довгі номери вручну — застосунок зчитає їх за вас.

ЩО ЗЧИТУЄ
• KIT-номер («кіт-номер») з коробки — QR-код або штрихкод
• Серійний номер тарілки — QR-код або штрихкод
• Серійний номер роутера — QR-код або штрихкод
• Starlink ID (ut…) — по мережі з тарілки
• Router ID — по мережі з роутера
• MAC-адресу роутера — по мережі
Позначте лише ті пункти, які вам потрібні, — застосунок запамʼятає вибір.

ЯК ЦЕ ПРАЦЮЄ
1. Підключіться до Wi-Fi Starlink.
2. Натисніть «Почати зчитування» й по черзі відскануйте коди — сканер підкаже, що саме шукати.
3. Застосунок сам опитає тарілку й роутер і заповнить решту полів.
Будь-яке значення можна звірити, виправити вручну або пересканувати.

НАДСИЛАННЯ Й ОБЛІК
• Дані комплекту — в Telegram, Viber, WhatsApp, Signal, SMS чи поштою однією кнопкою
• Історія всіх зчитувань, згрупована по днях
• Виберіть кілька комплектів — і надішліть їх одним повідомленням
• Або лише перелік KIT-номерів, по одному в рядку, — зручно для звітів і таблиць
• Власні примітки до кожного комплекту: адреса, клієнт, стан обладнання
• Якщо термінал уже зчитували, застосунок помітить це й запропонує оновити запис

ТАКОЖ
• Сканер читає QR, Data Matrix і штрихкоди; є ліхтарик і зум для дрібних наліпок
• Сканування працює без інтернету
• Тест швидкості інтернету через ваш Starlink
• Демо-режим: подивіться, як усе працює, навіть без Starlink поруч
• Мови: українська, англійська, польська, іспанська, німецька

ДЛЯ КОГО
Для монтажників і сервісних інженерів, волонтерів і фондів, які передають термінали, звʼязківців, IT-служб компаній і громад — для всіх, хто веде облік обладнання Starlink.

ПРИВАТНІСТЬ
Усі зчитані дані зберігаються лише на вашому телефоні. Застосунок не має власних серверів і не передає ваші номери розробнику чи третім особам. Вихідний код відкритий для перегляду на GitHub.
